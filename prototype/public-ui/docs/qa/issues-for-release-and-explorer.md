# Issues found in release 2.0.0-rc.1 and the current explorer

The prototype's design and evaluation rounds found these problems in the release data or in the current explorer (`site/`), not in the prototype. The prototype hides or works around most of them at display time (see `docs/DATA.md` › Display wording). They should be fixed at source so that the explorer and the release files are right too. Each one is written so it can be filed as a GitHub issue.

| # | Severity (0–4) | Where | Problem | Suggested fix |
|---|---|---|---|---|
| 1 | 4 | Release data: enactment notes on two competency records; shown on the explorer, for example `site/_site/competencies/cmp-8qwcq3r/` | Six enactment notes describe categories of Tribal-held content. That makes the policy sentence "These pages neither show nor describe it" untrue. | Remove the clauses at source. Add a lint rule for held-description phrasing, not only trigger words. The prototype's `tools/verify-data.mjs` has one (`5-held-description`). |
| 2 | 3 | Explorer: `site/src/_includes/macros.njk`, about line 53 | 108 negated crosswalk rows (102 ESCO, 5 SOC, 1 OPM) render as matches, because the template ignores `predicate_modifier`. | Render negated rows as "not a match", or leave them out of the match lists. |
| 3 | 3 | Explorer text: the HR notice ("describes work for development and planning"), the use notice ("For development and planning only") and the authorship line ("AI agents checked the facts against sources") | No rc.1 record reaches the develop tier, and most records cite no source. | Use the tier-true wording, e.g. "This view describes work. It is not ready for training or development plans." State provenance by whether each record cites a source. |
| 4 | 3 | Flagship report | The "describing and developing" wording claims a use no record has reached. | Say "describing" until records reach the develop tier. |
| 5 | 2 | `vocab/sector_actors.yaml` (5 labels) and `vocab/crafts.yaml` (SC3) | Unquoted labels with commas inside YAML flow mappings are cut at the first comma. For example, "Special district (water, sanitation, …)" parses as "Special district (water". The rest of the label becomes keys with null values. | Quote those `prefLabel` values. Add a lint rule: no null-valued keys in a vocabulary entry. |
| 6 | 2 | Enactment `data/v2/modules/envhealth/enactments/ENA-79W2WN0.yaml` (on "Develop and resolve environmental enforcement cases") | "Case records come from SL-C07 inspections…": SL-C07 resolves to "Review plans and evaluate sites for environmental health permits", whose definition excludes inspections. | Point the note at the inspection competency, or reword it. |
| 7 | 2 | Release data: nonprofit variants of the field resource technician and the programme manager | The employer subtype is "Land trust". The vocabulary also has "Conservation or service corps", which may be the intended subtype for corps-type work. | Data owner to confirm. |
| 8 | 2 | Release data: free-text notes | Drafting-agent work codes (SL-053, DB-C49, TR-09, "FH Phase 2 … X1"), evidence tags and decision-record references appear in prose a reader can't resolve. | Write notes for readers, and keep codes in structured fields. |
| 9 | 2 | Source registers (`docs/research/*/sources.csv`) | Five sources name a local path on a build machine as the publisher (DC-033, DC-035, DC-036, DC-037, LM-017). Two use `.md` file names as titles (FH-039, FH-040). | Use publisher names and document titles. |
| 10 | 2 | Release data: private-sector job framework rows | Rows show only an ID, such as "Private-sector job framework entry PJ-001", with no title. | Add titles, or don't publish untitled rows. |
| 11 | 2 | Release data: "Can grow into" on role profiles | Some next steps are roles at a lower level, for example Geospatial → Ground-truth steward. | Decide whether moves down are listed, and label them if they are. |
| 12 | 1 | Release data: Field resource technician crosswalks | The role has no OPM 0462 crosswalk, so a search for "forestry technician" finds the series before the role. The prototype adds an editorial synonym. | Check whether a 0462 link is warranted. |
| 13 | 1 | State classes | Only 4 jurisdictions (Texas, Washington, Philadelphia, Lewis County), so the "compare a state class with a role" scenario fails. | Coverage roadmap. |
