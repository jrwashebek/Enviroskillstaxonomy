# Accessibility

{% hint style="info" %}
Draft release 2.0.0-rc.1. Drafted by AI agents, not yet reviewed by people. [What this means](../how-to-read/drafted-by-ai-agents.md)
{% endhint %}

We want everyone to be able to use EMST. That includes people who use a screen reader, a keyboard alone, zoom or high-contrast colors.

## Our target

The target is WCAG 2.2 at level AA. This guidebook has not had an accessibility audit, so we do not claim that it meets the target.

## Who controls what

- **We write the content.** We control the words, the headings, the tables and the links.
- **GitBook runs the site.** GitBook controls the layout, the menus, search and page actions. As of November 2026, GitBook does not publish a statement of how well its sites meet WCAG.

## What we do in the content

- Headings go in order, with one main heading per page.
- Link text says where the link goes.
- Tables have a header row.
- Nothing depends on color alone. Every status is written in words.
- Plain words, aiming for US grade 8 or lower. Abbreviations are spelled out in the [glossary](../how-to-read/glossary.md).

## Other ways to read the same pages

- **Plain files.** Every page here is also a plain Markdown file [on GitHub](https://github.com/jrwashebek/Enviroskillstaxonomy/tree/design/public-interface-prototype/prototype/public-ui/gitbook/site).
- **The explorer.** The EMST explorer is designed to work with a keyboard alone, fit small screens and never rely on color alone. It has not had a full audit either.

## Known limits

- No one who uses assistive technology has tested this guidebook yet.
- Automated checks find only some problems.
- Much of the record text uses long sentences and technical words. Plainer wording for records has not been written yet.

## Report a barrier

Tell us on [GitHub Issues](https://github.com/jrwashebek/Enviroskillstaxonomy/issues). You need a free account. If the barrier is part of GitBook itself, we can pass it on to GitBook.
