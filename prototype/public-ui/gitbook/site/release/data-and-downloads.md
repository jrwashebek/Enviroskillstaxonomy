# Data and downloads

{% hint style="info" %}
Draft release 2.0.0-rc.1. Drafted by AI agents, not yet reviewed by people. [What this means](../how-to-read/drafted-by-ai-agents.md)
{% endhint %}

EMST is open data. You may copy, change and share it for any purpose, without asking.

## Get the data

The release files are built from the project's GitHub repository. They are not yet posted as a download. Until they are, you can build them yourself by following the README in [EMST on GitHub](https://github.com/jrwashebek/Enviroskillstaxonomy).

To take one role's tasks with you, use “Copy tasks as text” or “Download CSV” on the role page.

## What a release contains

| File | What it holds |
|---|---|
| Spreadsheet files (CSV) | Tables of roles, tasks, competencies and other records. They open in any spreadsheet program. |
| Full data set (JSON-LD) | Every record and link in one file, for developers. |
| Vocabulary file (SKOS) | The terms and how they relate, for data and library systems. |
| Link files | Every link the AI agents suggested to O\*NET, ESCO, OPM series or state classes. Each one comes with the agent's notes and review status. |
| Release notes | What changed, what is held back, and known issues. |

To see which kinds of environmental work this release has roles for, and which it does not, read [What EMST covers](../start-here/what-emst-covers/README.md).

## How to cite

> **Citation:** EMST project lead (2026). Environmental Management Skills Taxonomy, draft release 2.0.0-rc.1. Drafted by AI agents; not yet reviewed by people. https://github.com/jrwashebek/Enviroskillstaxonomy

Each record also has “Copy citation”, which adds the record's ID.

## Record IDs

Each record has an ID, such as emst:core/ROL-ZJFCC09. IDs are candidates until version 2.0.0, so they may still change. Always cite the release with the ID.

## Keep the caveats with the data

If you reuse or share EMST, keep “Drafted by AI agents. Not yet reviewed by people.” with it, and keep each record's use label. Leave “Assessment pending” as it is. Never turn it into a zero or a blank.
