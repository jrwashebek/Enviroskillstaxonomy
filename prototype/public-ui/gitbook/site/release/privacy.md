# Privacy

{% hint style="info" %}
Draft release 2.0.0-rc.1. Drafted by AI agents, not yet reviewed by people. [What this means](../how-to-read/drafted-by-ai-agents.md)
{% endhint %}

EMST adds nothing to these pages that tracks you. GitBook, the company that hosts them, does collect some data.

## What GitBook collects

- GitBook's cookie statement says it uses Google Analytics on the sites it hosts, including this one, and sets cookies to do so. [GitBook's cookie statement](https://gitbook.com/docs/policies/privacy-and-security/statement/cookies)
- Like any host, GitBook may keep basic server logs, such as the address a request came from.
- If a page asks whether it was helpful, your answer goes to GitBook. It does not reach EMST's GitHub. To report a problem, use [GitHub Issues](https://github.com/jrwashebek/Enviroskillstaxonomy/issues).

## What EMST's pages hold

These pages hold no personal data. EMST records describe work, not people.

## Other ways to read the same pages

- Every page here is also a plain Markdown file [on GitHub](https://github.com/jrwashebek/Enviroskillstaxonomy/tree/design/public-interface-prototype/prototype/public-ui/gitbook/site). GitHub has its own privacy rules.
- The EMST explorer sets no cookies and runs no analytics.

## Links to other sites

Links to GitHub, O\*NET, state job class documents and other sites take you away from this guidebook. Those sites have their own privacy rules.
