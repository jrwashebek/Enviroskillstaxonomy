# Release status

{% hint style="info" %}
Draft release 2.0.0-rc.1. Drafted by AI agents, not yet reviewed by people. [What this means](../how-to-read/drafted-by-ai-agents.md)
{% endhint %}

Before anyone outside the project may rely on a release, it must pass eight checks. This page shows how release 2.0.0-rc.1 did, as of 25 October 2026. Scripts and AI agents ran the checks. No person has signed them.

{% hint style="warning" %}
**Not cleared for publication.** Release 2.0.0-rc.1 is a test version for a pilot preview. It is not cleared for publication outside the project. Checks not passed: 6 and 7.
{% endhint %}

## The eight checks

| Check and result | What it covers |
|---|---|
| 1. Automated tests: passed | The automated tests ran when the release was built. |
| 2. Size of the core list: passed | The core list of competencies stays within its planned size. |
| 3. Use limits: passed | Every record states its use. None is cleared for hiring. No rating is shown unless raters were shown to agree. |
| 4. Scope: passed | The first group of work areas is in. Later groups are left out, apart from a few named early drafts. |
| 5. Roles: passed with conditions | All planned roles are drafted. Some federal series and state class views are missing, because no person has checked the links they would be built from. |
| 6. Links to other systems: not passed | No person has reviewed a sample of the links to O\*NET, OPM series, ESCO or state classes. For O\*NET tasks, the two AI coders also agreed too little. |
| 7. Human sign-off: not passed | No named subject-matter expert has reviewed the release, and the EMST project lead has not signed it. |
| 8. Early decisions: passed | The project lead's first decisions are on record. |
