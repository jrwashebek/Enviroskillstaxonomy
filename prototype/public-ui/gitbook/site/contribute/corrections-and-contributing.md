# Corrections and contributing

{% hint style="info" %}
Draft release 2.0.0-rc.1. Drafted by AI agents, not yet reviewed by people. [What this means](../how-to-read/drafted-by-ai-agents.md)
{% endhint %}

If you do this work, you can make EMST better. Tell us when a task, a level or a link is wrong, or when work is missing.

## How to report a problem

- Copy the record reference. It names the record and the release.
- Open GitHub Issues. You need a free GitHub account, and what you post is public.
- Start a new issue. Paste the reference, then say what is wrong and what it should say.
- Do not include names, email addresses or anything about a staff member.
- Watch the issue on GitHub for replies.

[Open GitHub Issues](https://github.com/jrwashebek/Enviroskillstaxonomy/issues)

{% hint style="info" %}
**Before you post.** GitHub needs a free account, and issues are public. If you work for an agency, check its rules on posting in public first.
{% endhint %}

## What happens next

For now, the EMST project lead decides on changes. The project's draft contributing guide sets time limits for sorting each issue, and asks for reasons when a change is turned down. Accepted changes go into a later release.

## No GitHub account?

A way to send corrections without a GitHub account is under consideration. For now, GitHub is the only route.

## Report misuse

If you see EMST used to screen, rank, rate or lay off people, please tell us on GitHub Issues. Leave out the names of people.

## Suggest a role or task we're missing

Open an issue and describe the work in your own words: the job title, the main tasks and the kind of employer. If you came here from a search, your search words are shown on this page so you can copy them.

Read the full guide: [Contributing to EMST](https://github.com/jrwashebek/Enviroskillstaxonomy/blob/main/docs/governance/CONTRIBUTING.md).
