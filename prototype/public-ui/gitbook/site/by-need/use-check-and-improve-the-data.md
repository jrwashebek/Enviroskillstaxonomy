# Use, check and improve the data

{% hint style="info" %}
Draft release 2.0.0-rc.1. Drafted by AI agents, not yet reviewed by people. [What this means](../how-to-read/drafted-by-ai-agents.md)
{% endhint %}

EMST is open data. You may copy, change and share it for any purpose, without asking.

## Get and cite the data

[Data and downloads](../release/data-and-downloads.md) says what a release contains, how to get it and how to cite it.

## Keep the caveats with the data

If you reuse or share EMST, keep “Drafted by AI agents. Not yet reviewed by people.” with it, and keep each record's use label. Leave “Assessment pending” as it is. Never turn it into a zero or a blank.

## Use EMST with AI tools

- **Read the pages as Markdown.** GitBook, which hosts this guidebook, offers each page as plain Markdown, which AI tools read well. The same files are also [on GitHub](https://github.com/jrwashebek/Enviroskillstaxonomy/tree/design/public-interface-prototype/prototype/public-ui/gitbook/site).
- **Check what an AI tool tells you.** AI tools may drop the caveats: the use label, “Assessment pending” and “Drafted by AI agents”. Check the answer against the record, and put the caveats back.
- **Don't ask an AI tool to screen or rank people with EMST.** That is not an allowed use, whoever or whatever does it.
- **This guidebook's AI assistant is off.** It will be switched on only after it passes a set of test questions, including questions it must refuse, such as whether someone qualifies for a job.

## Check what a record rests on

Every record carries labels that say how far to trust it:

- [What it may be used for](../how-to-read/uses.md)
- [Who drafted it](../how-to-read/drafted-by-ai-agents.md) and its [review status](../how-to-read/review-status.md)
- [Its evidence label](../how-to-read/evidence-labels.md): sourced, judgment or speculation

Many records cite no source yet. [Release status](../release/status.md) shows which release checks have passed.

## Help improve it

If a task, a level or a link is wrong, or work is missing, tell us on GitHub. [Corrections and contributing](../contribute/corrections-and-contributing.md)
