# Develop people and programs

{% hint style="info" %}
Draft release 2.0.0-rc.1. Drafted by AI agents, not yet reviewed by people. [What this means](../how-to-read/drafted-by-ai-agents.md)
{% endhint %}

EMST lists the competencies behind each role's tasks, with draft levels for each one. Course designers, trainers and supervisors can use it to explore what a program could cover. In this release, it is not ready for training plans.

{% hint style="warning" %}
**Explore only, for now.** All 223 competencies and their levels are explore only. No record reaches this use yet. First, practitioners from at least three kinds of employer must review the content. Then an expert panel must agree on the level of each skill statement.
{% endhint %}

## What you can do now

- **Map a course or training program to the tasks a role does.** Tasks may be used to describe and plan, so this use is open.
- **Explore what a new course might cover,** such as a class on prescribed fire.
- **Spot new skills to keep an eye on.** 26 competencies are marked “On watch” in What's changing.
- **Look for formation tasks.** A [formation task](../how-to-read/formation-tasks.md) is learned through supervised practice on the job, not from a course alone. These tasks show where a program needs field time and mentoring as well as classes.

## Steps

1. **Choose a role or a competency.** Browse the competencies by subject module, or start from a role.
2. **Read the competency's draft levels.** They are marked explore only, because no expert panel has placed them yet.
3. **Check the tasks the competency supports.** They show what the skill is used for at work.
4. **Match what you teach to the tasks, not to the levels.** Tasks may be used to describe and plan. Levels may only be explored.

## You can't, yet

- State it as fact in a workforce plan or report.
- Build a training plan or task book from it.
- Use it in hiring, or to set a job's grade or pay.
- Use it to rate staff or to decide who to lay off.

## What it would take

Training shapes people's careers. It needs content that practitioners have checked, with skill levels that experts agree on. See [What you can use EMST for](../how-to-read/uses.md) for what the train-and-develop use will allow once a record reaches it.
