# Review status

{% hint style="info" %}
Draft release 2.0.0-rc.1. Drafted by AI agents, not yet reviewed by people. [What this means](drafted-by-ai-agents.md)
{% endhint %}

| Status | What it means |
|---|---|
| Not yet reviewed by people | No person has reviewed this record yet. |
| Spot-checked | A person reviewed a sample of records like this one. |
| Reviewed by a person | A named reviewer read and checked this record. |
| Passed its use test | It passed the checks set for its use, such as an expert panel and a study of how well raters agree. |
| Reference set | It is part of a small set that two people coded on their own. The set is used to test other coding. |

In release 2.0.0-rc.1, every record is “Not yet reviewed by people”.
