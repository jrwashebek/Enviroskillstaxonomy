# Source grades (A to D)

{% hint style="info" %}
Draft release 2.0.0-rc.1. Drafted by AI agents, not yet reviewed by people. [What this means](drafted-by-ai-agents.md)
{% endhint %}

Signals about change carry a grade for their source. The grade rates the source, not the claim, and it is not a statistic. The AI agent that entered the signal set the grade. No one has graded it again from the original source yet.

| Grade | What it means |
|---|---|
| A | Strong source: original data or a peer-reviewed study |
| B | Good source: a trusted secondary source that names its original data |
| C | Limited source: one secondary source or one practitioner's report |
| D | Weak source: an unchecked story or a vendor's claim |
