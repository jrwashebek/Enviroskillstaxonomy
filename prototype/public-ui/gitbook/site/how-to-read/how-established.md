# How established the work is

{% hint style="info" %}
Draft release 2.0.0-rc.1. Drafted by AI agents, not yet reviewed by people. [What this means](drafted-by-ai-agents.md)
{% endhint %}

This label is about the work in the world, not about EMST's description of it.

| Label | What it means |
|---|---|
| On watch | Something may be starting in this work, but it is not yet shown to exist across the sector. It is dropped if no new evidence comes in by its review date. |
| Proposed | A draft definition exists. Early evidence points to it, such as a new rule or several signals. |
| Emerging | Seen in real work, such as job postings at more than one kind of employer, but not yet long-standing. |
| Established | Long-standing work in the sector. This says the work is real. It does not say that EMST's description of it has been checked. |
| Declining | Demand for this work is falling, or other work is taking its place. |
| Withdrawn | No longer current. It is kept for the record and is not for any use. |
| Lapsed | A watch item that ended because no new evidence came in by its review date. |
| Merged | Combined into another record. Links lead to that record. |
