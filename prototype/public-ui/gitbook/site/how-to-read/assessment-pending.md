# Assessment pending

{% hint style="info" %}
Draft release 2.0.0-rc.1. Drafted by AI agents, not yet reviewed by people. [What this means](drafted-by-ai-agents.md)
{% endhint %}

Some values need people to rate them before we can show them. Until a study checks them, EMST shows “Assessment pending” instead of a number. Pending never means zero or unimportant.

These values are pending:

- Importance
- Share of work time
- Whether it is critical
- Whether it is needed on day one
- Mix of field, data and policy skill
- Exposure to AI and automation
- Type of work

> **On a role page:** Assessment pending. None of this role's tasks has been assessed yet. The order of the list says nothing about importance.

These values will appear after a study with practitioners checks them. No study has reported yet.

Some tasks also have codes from EMST version 1, made by one analyst with an AI assistant. They sit in a closed drawer marked “not for decisions”. They are never counted, averaged or put in charts.
