# Evidence labels: E, J and S

{% hint style="info" %}
Draft release 2.0.0-rc.1. Drafted by AI agents, not yet reviewed by people. [What this means](drafted-by-ai-agents.md)
{% endhint %}

Each record carries one letter that says what it rests on.

| Label | What it means |
|---|---|
| E: Sourced | Based on a source that was read and is cited. |
| J: Judgment | A reasoned judgment with its basis stated. In this release, an AI agent made it, not a person. |
| S: Speculation | Plausible but not yet supported. It says what would confirm it or rule it out. |
