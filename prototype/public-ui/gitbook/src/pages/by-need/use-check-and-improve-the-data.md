## Use EMST with AI tools

- **Read the pages as Markdown.** GitBook, which hosts this guidebook, offers each page as plain Markdown, which AI tools read well. The same files are also [on GitHub]({{markdownCopy}}).
- **Check what an AI tool tells you.** AI tools may drop the caveats: the use label, “Assessment pending” and “Drafted by AI agents”. Check the answer against the record, and put the caveats back.
- **Don't ask an AI tool to screen or rank people with EMST.** That is not an allowed use, whoever or whatever does it.
- **This guidebook's AI assistant is off.** It will be switched on only after it passes a set of test questions, including questions it must refuse, such as whether someone qualifies for a job.

## Check what a record rests on

Every record carries labels that say how far to trust it:

- [What it may be used for](page:how-to-read/uses.md)
- [Who drafted it](page:how-to-read/drafted-by-ai-agents.md) and its [review status](page:how-to-read/review-status.md)
- [Its evidence label](page:how-to-read/evidence-labels.md): sourced, judgment or speculation

Many records cite no source yet. [Release status](page:release/status.md) shows which release checks have passed.
