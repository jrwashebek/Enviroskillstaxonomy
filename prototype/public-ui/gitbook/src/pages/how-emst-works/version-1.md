EMST started as version 1. One analyst wrote it, working with an AI assistant. Version 2, the current draft, was rebuilt from it by AI agents to new rules.

## How version 1 was organized

Version 1 had {{v1Domains}} domains, {{v1SkillAreas}} skill areas, {{v1Comps}} competencies and {{v1Tasks}} tasks.

## What carried over

- Every version 1 competency and task carried over into version 2 as a starting point. Records that came from version 1 say so, and a link file maps each version 1 item to what replaced it.
- Some text still uses version 1 wording. It says “Wording carried over from EMST version 1”.
- The domains and skill areas are no longer how EMST is organized. They are kept as labels in the data, so older work can still be traced.

## Why version 1 is history only

- Version 1 is not published as a standard. It stays available as a clearly labelled history.
- One analyst made version 1's ratings, with an AI assistant. Its statistics, such as how many tasks were exposed to AI, may be cited only as part of the method's history. They are not current findings.
- Some tasks show version 1 codes. They sit in a closed drawer marked “not for decisions”, and they are never counted, averaged or put in charts.

## Where to find it

A frozen copy of version 1 is in the [GitHub repository]({{v1Url}}).
